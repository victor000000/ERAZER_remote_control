# Release 1.0.2

SQX readiness now requires a complete generated-strategy count on its own
status line. Nonnegative whole counts with optional comma grouping are accepted.
An incomplete count keeps startup readiness pending until a valid status
arrives or the wait expires.

Offline unit tests cover truncated, fractional, malformed and multiline
counts. The [testing guide](../testing.md) covers the Windows PowerShell 5.1 and
PowerShell 7 matrix, Python documentation checks, 90% module coverage gate,
and synthetic fixtures. Use the [operations runbook](../safe-operations.md)
to verify live task and SQX state.
